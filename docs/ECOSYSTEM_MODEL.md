# Ecosystem model

Target entity for V2 Phase 1. Today a “ecosystem” in the UI is a **token** with an `EcosystemScore`.

An Ecosystem groups tokens, contracts, chains, wallets/clusters, pools, venues, developers, narratives, governance, treasury, events, risks, observations.

Bootstrap: one candidate ecosystem per YAML token (`DISCOVERED` / unverified). Automatic formation from multiple signals stays a candidate — **never auto-VERIFIED** (same rule as pair discovery).

Lifecycle is a separate machine from verification level. VERIFIED ≠ SAFE.
