# Competitive positioning

Do not compete on dashboard count. Classify work before building.

| Kind | Examples | Our stance |
| --- | --- | --- |
| COMMODITY | Price, volume, whale *alert*, wallet tracker | Show if we have evidence; never the pitch |
| DIFFERENTIATOR | Historical wallet behaviour, ecosystem graph, lifecycle | Build on Twin + history |
| MOAT CANDIDATE | Ecosystem Digital Twin, behavioural similarity, evidence graph | Accumulate state over time |
| MOAT | Historical reconstruction + relationship memory + research corpus | Years of valid observations |

Pitch:

> **Digital Twin + Intelligence Layer for crypto ecosystems.**

Not: trading bot, price predictor, explorer, wallet tracker, generic chatbot, memecoin screener.

Differentiation: **context + temporal state + relationships + simulation + evidence + autonomous research** (research is grounded; execution stays off).

North star (V2 §88): “What is happening in crypto ecosystems now?” → Twin → history → relations → risk → evidence → explain → what-if → Investigate Next.
